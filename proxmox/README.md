# Proxmox

## Descrição

O Proxmox é a plataforma de virtualização utilizada no meu homelab.

Atualmente utilizo o Proxmox para executar máquinas virtuais e organizar os serviços do laboratório.

## Máquinas virtuais

### Home Assistant

VM utilizada para executar o Home Assistant.

### OpenMediaVault

VM utilizada para armazenamento e execução de serviços através de Docker.

## Objetivos de estudo

- Aprender administração de máquinas virtuais
- Aprender gerenciamento de recursos
- Estudar redes em ambientes virtualizados
- Estudar armazenamento
- Aprender backup e recuperação
- Entender melhor administração de servidores Linux
